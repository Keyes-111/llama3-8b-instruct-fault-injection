# Llama-3-8B-Instruct HBM Fault Injection

本项目研究 Llama-3-8B-Instruct 在 HBM 1→0 非对称位翻转故障下的模型容错能力。

实验覆盖以下模型表示：

- FP16
- Quanto INT8
- AutoAWQ INT4 W4A16
- SpECC 保护的 INT8 模型
- 面向 AWQ INT4 权重的故障注入实验

故障模型模拟 HBM 电容泄漏造成的 1→0 bit flip。每轮实验从干净模型重新加载，在指定权重范围内按照固定随机种子均匀、无放回地选择初始值为 1 的有效 bit，并将其翻转为 0。实验统一采用约 0.3% BER，并记录实际翻转数量和实际 BER。

主要评测数据集：

- MMLU：通用知识和推理能力
- MathQA：数学问题求解能力
- HumanEval：代码生成能力

项目还包含基于冗余编码和 SpECC 的保护机制，用于评估量化模型在 HBM 持久性故障下的恢复能力。所有实验脚本均记录模型配置、量化方式、故障注入范围、随机种子、GPU、翻转数量、BER 和最终准确率。

注意：模型文件、完整运行日志、原始 mask、缓存和大规模结果文件不上传到 GitHub；仓库仅保存可复现实验所需的程序代码、配置文件、说明文档和结果汇总。
